PHP FUNDAMENTALS — NOTES (Up to Mixed Arrays)

1. What is PHP

PHP is a server-side scripting language. PHP code runs on the server; the browser receives only the output generated by PHP. PHP is loosely typed (data types are assigned automatically).

----------------------------------------------------------------

2. Running PHP

2.1 CLI (Command Line Interface)

Used mainly for learning and scripting.

Command:
php filename.php

Characteristics:
- Recommended for learning
- New line character: \n
- HTML tags (e.g. <br>) are printed as plain text
- Output is shown directly in the terminal

----------------------------------------------------------------

2.2 Browser (Server Execution)

PHP runs through a web server (e.g. Apache or PHP built-in server).

Characteristics:
- Output is rendered as HTML
- Line break is created using <br>
- Browser ignores \n

----------------------------------------------------------------

3. Basic PHP syntax

- PHP code starts with `<?php` (the closing tag `?>` is optional and usually omitted)
- Every PHP statement ends with a semicolon (`;`)

----------------------------------------------------------------

4. Variables

Variables store values.

Rules:
- Variables start with `$`
- Variable names are case-sensitive (`$name` and `$Name` are different)
- Names must start with a letter or underscore (`_`)

Examples:
$name = "Pranav";
$age = 22;
$isDeveloper = true;

----------------------------------------------------------------

5. Data types

PHP assigns data types automatically.

Common types:
- string
- integer
- float
- boolean
- array

Examples:
$name = "Dexter"; // string
$age = 22; // integer
$height = 5.9; // float
$isActive = true; // boolean

----------------------------------------------------------------

6. Debugging variables

6.1 `var_dump()`

Used to inspect variables in detail.

Example:
var_dump($name);

Characteristics:
- Displays type and value
- Very detailed
- Intended for debugging only

----------------------------------------------------------------

6.2 `print_r()`

Used mainly for arrays.

Example:
print_r($array);

Characteristics:
- Cleaner, more readable output for arrays
- Less detailed than `var_dump()`
- Intended for debugging only

----------------------------------------------------------------

7. Output methods

7.1 `echo`

Used to output text. No return value; most commonly used.

Example:
echo "Hello";

----------------------------------------------------------------

7.2 `print`

Used to output text. Returns `1`.

Example:
print "Hello";

----------------------------------------------------------------

8. Strings

PHP supports double quotes (`" "`) and single quotes (`' '`).

8.1 Double quotes
- Variables are interpolated
- Escape characters work

Example:
$name = "Dexter";
echo "Hello $name\n";

----------------------------------------------------------------

8.2 Single quotes
- Variables are treated as literal text
- Escape characters do not work (except `\\` and `'`)

Example:
echo 'Hello $name\n';

----------------------------------------------------------------

9. String concatenation

Use the dot operator (`.`) to join strings.

Example:
echo "Hello " . $name;

----------------------------------------------------------------

10. CLI vs Browser output

CLI: new line character is `\n`
Browser: line break is `<br>`

----------------------------------------------------------------

11. Conditions

11.1 `if` / `else`

Example:
if ($age >= 18) {
	echo "Adult";
} else {
	echo "Minor";
}

----------------------------------------------------------------

11.2 `elseif`

Example:
if ($marks >= 90) {
	echo "Grade A";
} elseif ($marks >= 60) {
	echo "Grade B";
} else {
	echo "Fail";
}

----------------------------------------------------------------

12. Comparison operators

==  equal
!=  not equal
>   greater than
<   less than
>=  greater than or equal
<=  less than or equal

----------------------------------------------------------------

13. Logical operators

&&  AND
||  OR
!   NOT

Example:
if ($age >= 18 && $isDeveloper) {
	echo "Adult developer";
}

----------------------------------------------------------------

14. Arrays

Arrays store multiple values in a single variable.

14.1 Indexed arrays

Example:
$fruits = ["Apple", "Banana", "Orange"];
echo $fruits[0];

Note: index starts from 0

----------------------------------------------------------------

14.2 Associative arrays

Example:
$user = [
	"name" => "Dexter",
	"age" => 22
];

echo $user["name"];

Note: uses key => value pairs

----------------------------------------------------------------

14.3 Mixed / nested arrays

Example:
$profile = [
	"user" => [
		"name" => "Dexter",
		"age" => 22
	],
	"skills" => ["PHP", "Laravel", "Git"],
	"isActive" => true
];

Accessing values:
echo $profile["user"]["name"];
echo $profile["skills"][1];

----------------------------------------------------------------

15. Debugging arrays

Examples:
print_r($profile);
var_dump($profile);

Notes:
- `print_r()` → readable
- `var_dump()` → detailed

----------------------------------------------------------------
